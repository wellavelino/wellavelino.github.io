se-informe: what Brazilian deputies spend, traced to the official file

A public site with the directory of the Brazilian Congress and the expenses of its deputies. Every number on it can be followed back to the record it came from.

Role
Solo builder
Year
2026 — now
Stack
Python 3.11 · SQLite · React + TypeScript
Link
seinformebrasil.org ↗
01

The problem

Brazil's Chamber of Deputies publishes how each deputy uses the CEAP, the allowance that pays for their mandate. The data is public, but it comes as annual files that take work to open, filter and check.

02

What I did

I built a collector, a validated database and a static site. Three parts carry it:

Data Official sources

Directory of deputies and senators from the official APIs. CEAP expenses from the annual files the Chamber has published since 2008.

Evidence Every record traced

Each expense keeps its official file, CSV ordinal and the SHA-256 of the ZIP and CSV it came from.

Product Trends and CSV

Monthly trends, categories and suppliers for each deputy, with a CSV export of whatever filters are active.

Honesty about gaps is part of the design. Negative adjustments are preserved, a month with no rows is never shown as zero spending, and Senate expenses are not integrated yet, which the interface says plainly.

A daily worker refreshes the data at 21:00 UTC on a private copy, validates it and only then publishes; a failure brings back the previous version. The frontend is compiled to static assets, so the production server runs no Node.

03

Where it stands

The first milestone is live: the directory and the deputy expenses, with the evidence behind them.

Votes, attendance, mandate history and editorial review are planned milestones, not features of the site today.

04

What I'd do next

Integrate Senate expenses. The directory already covers senators; their spending is the visible gap.

Add history and mandates. Proven periods in office would let the numbers be read against the time actually served.

Add votes and attendance. They would answer the next question people ask, from the same kind of official source.
