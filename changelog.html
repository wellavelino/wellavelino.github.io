## CONTRIBUTING.md

House rules

rule 01

Nothing ships unverified.

Static checks, unit, integration and end-to-end tests gate every push. After each deploy I test the change live.

rule 02

Name the commit that broke it.

Every bug fix starts with a failing test and finds the change that introduced the bug.

rule 03

Beat the baseline, in numbers.

A model or heuristic ships only when it beats the simple version on measurements, never on impressions.

rule 04

Agents get roles, reviews and budgets.

Each model has a clear job, with review and cost limits, so AI adds speed without losing quality.
