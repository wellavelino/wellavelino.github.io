Pull-out poster

House rules.

01

Nothing ships unverified.

Static checks, unit, integration and end-to-end tests gate every push. After each deploy I test it live.

02

Name the commit that broke it.

Every fix starts with a failing test and finds the change that caused the bug.

03

Beat the baseline, in numbers.

A model ships only when it beats the simple version on measurements.

04

Agents get roles, reviews and budgets.

Each model has a clear job, so AI adds speed without losing quality.
